# Template: Projeto Básico Xmova

> Este template serve como ponto de partida para novos projetos xmova. Copie e adapte conforme necessário.

## Estrutura de Projeto Recomendada

```
meu-projeto-xmova/
├── src/
│   ├── core/                # Lógica principal do domínio
│   ├── services/            # Serviços e integrações
│   ├── utils/               # Utilitários reutilizáveis
│   └── main.[ext]           # Ponto de entrada da aplicação
├── tests/
│   ├── unit/                # Testes unitários
│   └── integration/         # Testes de integração
├── docs/
│   └── README.md            # Documentação do projeto
└── README.md                # Visão geral do projeto
```

## Próximos Passos

Após configurar seu projeto com este template:

1. Defina os requisitos do seu domínio.
2. Implemente os serviços necessários em `src/services/`.
3. Adicione testes unitários em `tests/unit/`.
4. Documente os componentes principais em `docs/`.
5. Se descobrir novos padrões úteis, contribua de volta ao [xmova-knowledge-base](https://github.com/robertsoft/xmova-knowledge-base).
