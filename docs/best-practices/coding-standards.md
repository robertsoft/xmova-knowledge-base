## Princípios de Desenvolvimento

1. **Clareza sobre Esperteza:** Código legível é mais valioso do que código "inteligente".
2. **Consistência:** Siga os padrões estabelecidos neste repositório, mesmo que pareçam arbitrários.
3. **Documentação Inline:** Comentários devem explicar o *porquê*, não o *o quê*.
4. **Composição:** Prefira composição de pequenas unidades a grandes blocos monolíticos.
