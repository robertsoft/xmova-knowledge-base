# Contribuindo

Obrigado por contribuir para a Xmova Knowledge Base. Para manter qualidade e
consistência, siga estas diretrizes:

- Abra uma issue antes de começar mudanças significativas.
- Crie branches com nomes descritivos: `feature/`, `fix/`, `docs/`.
- Faça PRs direcionadas para `main` e solicite revisões de `CODEOWNERS`.
- Atualize `docs/` quando modificar comportamentos ou APIs.
- Inclua testes unitários quando relevante e garanta que o CI passe.

Formato de commit: use mensagens claras, por exemplo `feat:`, `fix:`, `chore:`.
